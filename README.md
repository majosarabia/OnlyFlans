OnlyFlans 🍮

Sitio web de venta de flanes con catálogo y formularios, desarrollado con Python y Django.

🎥 Demo en video: https://drive.google.com/file/d/1KujAGBB8-Z4WEbdoPQ6DGFGkQIWaRjPK/view?usp=sharing

Funcionalidades
Catálogo de flanes con sus productos
Formularios de contacto
Panel de administración para incluir tus flanes
Tecnologías: Python, Django y HTML
